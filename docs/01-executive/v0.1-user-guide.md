# SAGIHA v0.1 — Target First Useful Release

> [!NOTE]
> Defines target capabilities for the initial release. See [STATUS.md](../STATUS.md) for implementation status.

---

## 1. Target User & Value Proposition

- **Target User**: Senior engineers, maintainers, and autonomous engineering teams on complex Python codebases.
- **Core Value**: Reproducible, capability-secured automated issue resolution with pristine test gates and zero API lock-in.

---

## 2. Planned v0.1 Scope (By Delivery Block)

Sourced from the foundation review and [roadmap](../07-roadmap/phased-migration-matrix.md):

1. **Closed Autonomous Loop (Block 1 / Sprint 3)**
   - Commands: `sagiha run`, `sagiha replay --verify` with cassette-driven CI.
   - Capability dispatch, 5 core tools, minimal acceptance `Evaluator`, cassette record/replay.

2. **Standalone Evaluation Substrate (Block 2 / E0-lite)**
   - Commit-replay harvester ([ADR-0015](../08-decisions/0015-benchmark-target-repository.md)).
   - A/A noise floor measurement and pristine test gate validation.

3. **Isolated & Sandboxed Execution (Block 5 / S1)**
   - Containerized worktrees via Podman ([ADR-0016](../08-decisions/0016-container-runtime-podman.md)).
   - Path-scoped capability grants and multi-provider native SDK support ([ADR-0008](../08-decisions/0008-native-sdks-no-litellm.md)).

4. **AST Retrieval & Diagnostics (Block 4 / S2)**
   - Tree-sitter AST-bounded chunking + lexical (FTS5) and code-graph search (dense retrieval deferred per [ADR-0014](../08-decisions/0014-defer-dense-retrieval.md)).
   - Warm LSP supervisor for continuous soft scoring.

---

## 3. Differentiation

| Capability | Standard Assistants (Aider / OpenHands) | SAGIHA v0.1 |
| :--- | :--- | :--- |
| **Test Integrity** | Editable tests allow false passes | **Pristine Injected Test Gate** (`tests_unmodified`) |
| **Replay & Audit** | Re-executes network side-effects | **Record/Replay with `EffectClass`** (no re-execution of DESTRUCTIVE) |
| **Security** | Unrestricted shell / basic sandbox | **Container boundary + capability grants (CAR)** |
| **Evaluation** | Single noisy benchmark runs | **Commit-replay harvester + A/A noise floor** |

---

## 4. Getting Started (Planned Interface)

*Commands pending release; see [getting-started.md](../06-guides-and-patterns/getting-started.md) for scaffold verification.*

```bash
# Autonomous execution and verification
sagiha run --task "Fix issue #142" --config config.toml
sagiha replay --run-id <id> --verify

# Benchmark harvesting and noise floor measurement
sagiha bench harvest --repo . --max-commits 20
sagiha bench --suite internal --runs 2 --mode aa
```
