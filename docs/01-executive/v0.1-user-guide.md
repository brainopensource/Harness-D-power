# **SAGIHA v0.1 — Target First Useful Release**

> [!NOTE]
> **Product positioning (target).** This document defines the capabilities, user, and
> differentiation for the first *genuinely useful* release. It is **not** a claim that these
> features ship today. See [STATUS.md](../STATUS.md) for what is implemented; Sprint 3 / Blocks
> 1–2 are the path to a measurable coding loop.

---

## 1. **Target User & Use Case**

* **Target User:** Senior Software Engineers, Maintainers, and Autonomous Engineering Teams working on complex Python codebases.
* **Core Value Proposition:** Deterministic, reproducible, capability-secured automated issue resolution with **zero grader-editing cheating** and **zero API lock-in**.

---

## 2. **What v0.1 Aims to Ship (by block)**

Capabilities below are **planned**. Parenthetical block is the delivery slice from the
[foundation review](../rationale/reviews/2026-07-29-foundation-review.md) / [roadmap](../07-roadmap/phased-migration-matrix.md).

1. **Closed autonomous loop (Block 1 / Sprint 3):**
   - `sagiha run` / `sagiha replay --verify` with cassette-driven CI.
   - Capability dispatch, five built-in tools, minimal acceptance `Evaluator`.
   - Digest-matched record/replay (graded fidelity L1 first).

2. **Standalone evaluation substrate (Block 2 / E0-lite):**
   - Commit-replay harvester from a real repository ([ADR-0015](../08-decisions/0015-benchmark-target-repository.md)).
   - A/A noise floor; task success / cost / latency reports.
   - Grades SAGIHA (and later other agents) against pristine gates.

3. **Isolated & sandboxed execution (Block 5 / S1):**
   - Containerized worktree execution (Podman — [ADR-0016](../08-decisions/0016-container-runtime-podman.md)).
   - Path-scoped grants and human approval flow (Block 3 hardens policy first).
   - Multi-provider models via native SDKs ([ADR-0008](../08-decisions/0008-native-sdks-no-litellm.md)); local OpenAI-compatible path in Sprint 3.

4. **AST retrieval & diagnostics (Block 4 / S2):**
   - Tree-sitter AST-bounded chunking and **lexical (FTS5) + code-graph** retrieval.
   - Dense / vector tier **deferred** until a measured trigger ([ADR-0014](../08-decisions/0014-defer-dense-retrieval.md)).
   - Warm LSP supervisor as a soft-score signal (never a hard gate).

## 3. **Why Choose SAGIHA v0.1 Over Alternatives**

| Feature / Capability | Standard Coding Assistants (Aider / OpenHands) | SAGIHA v0.1 (target) |
| :--- | :--- | :--- |
| **Test Protection** | Candidate can edit tests to force a pass | **Pristine Injected Test Gate** (`tests_unmodified` hard gate) |
| **Replay & Audit** | Re-executes network/side-effects on replay | **Record/replay with EffectClass** (DESTRUCTIVE never re-executed) |
| **Security Perimeter** | Unrestricted local shell or vague sandbox | **Container boundary + capability grants (CAR)** |
| **Evaluation Rigor** | Single-run benchmark score (noisy) | **Commit-replay harvester + A/A noise floor** |

## 4. **Getting Started (when Sprint 3 / Block 2 land)**

# Sprint 3 — close the loop

sagiha bench --suite internal --runs 2 --mode aa
