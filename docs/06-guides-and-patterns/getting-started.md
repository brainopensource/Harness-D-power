# **Getting Started & Day-Zero Quickstart**

> [!NOTE]
> **Working Proposal Disclaimer**: This document represents a working architectural proposal for SAGIHA2 and will be iteratively refined as practical evaluations progress.

## **Day-Zero Simple Baseline Quickstart**
1. **Prerequisites**: Python 3.12+, Git, SQLite3.
2. **Configuration**: Create `config.toml` specifying LLM API keys, target workspace path, and autonomy policy.
3. **Execution**: Run the native microkernel orchestrator using the Day-Zero simple baseline (SQLite + in-memory STM + ReAct loop + stdio MCP tools).
