# ADR-0001: Project Name — SAGIHA

**Status**: Accepted
**Date**: 2026-07-28

## Context
Earlier drafts used competing expansions of the same acronym — "Super AGI Meta-Harness Agent of Agents" in one document, "Senior AGI Harness Architecture 2.0" in another — plus a stray "Meta Harness CoderAGI". Inconsistent naming in a specification is a reliable early symptom of documents drifting apart.

## Decision
The project is **SAGIHA — Super AGI Harness Agent**. Python package `sagiha`. No version suffix in the name.

## Consequences
One canonical expansion across the suite. The package name is short and importable. Dropping the "2" removes the implication of a predecessor that was never released.

## Reversal Conditions
A trademark conflict, or a public launch where the name tests poorly with the intended audience.
