# ADR-0001: Project Name — SAGIHA

**Status**: Accepted  
**Date**: 2026-07-28

## Context
Inconsistent names ("Super AGI Meta-Harness Agent of Agents", "Senior AGI Harness Architecture 2.0", "Meta Harness CoderAGI") across documentation.

## Decision
- Project name: **SAGIHA — Super AGI Harness Agent**.
- Python package name: `sagiha`.
- No version suffixes.

## Consequences
- Single canonical name across specs.
- Importable, short package name.

## Reversal Conditions
- Trademark conflict or poor public audience reception.
