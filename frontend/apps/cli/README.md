# @sagiha/cli

Ink + React + TypeScript terminal cockpit for SAGIHA's mocked phase. See
`docs/frontend/architecture.md` and `docs/sprints/sprint-fe-1.md` onward for scope.

## Requirements

- Node 22+
- pnpm (via `corepack enable`)

## Commands (grown sprint by sprint)

- `sagiha-mock --version` / `--help` — available as of FE-1.
